# Science Crossroads

Official website of **Science Crossroads**, a two-day conference exploring the role of ethics across the sciences.

**Event Details**

- **Dates:** March 6–7, 2027
- **Location:** KEDEA, Aristotle University of Thessaloniki, Greece
- **Organizers:** ACM AUTh Student Chapter, ReAcTiON, PATh
- **Participation:** Free of charge

## Tech Stack

- SvelteKit
- Svelte 5
- Vite

## Getting Started

```bash
git clone https://github.com/Alekosss/ScienceCrossroads.git
cd ScienceCrossroads
npm install
npm run dev
```

To make the development server accessible from other devices on your local network:

```bash
npm run dev -- --host
```
